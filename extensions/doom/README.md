# Play Doom

![Play Doom](../../images/Ableton%20Extension%20-%20Doom.png)
![Play Doom 2](../../images/Ableton%20Extension%20-%20Doom%202.png)

[⬇️ Download](../../download/doom.ablx)

Runs the original DOOM Shareware (1993) fully offline inside Ableton Live.

## Features

- **Fully offline** — No internet connection required; all game assets are bundled
- **Classic controls** — Arrow keys or WASD to move, Ctrl to fire

## How to use

Right-click any **Audio Track**, **MIDI Track**, or **Scene** → **Doom: Play Doom 🔫**.

Click the game area first to capture keyboard input.

| Action | Key |
|---|---|
| Move | Arrow keys or WASD |
| Fire | Ctrl |
| Open door / activate | Space |
| Run | Shift |
| Menu | Esc |
