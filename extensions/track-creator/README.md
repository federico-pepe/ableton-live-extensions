# Track Creator

![Track Creator](../../images/Ableton%20Extension%20-%20Track%20Creator.png)

[⬇️ Download](../../download/Track-Creator-0.0.6.ablx)

Creates multiple audio or MIDI tracks at once from a simple dialog.

## Features

- **Batch creation** — Create 1–64 tracks in a single action
- **Audio or MIDI** — Choose the track type for the entire batch
- **Auto-naming** — Single tracks get the exact name entered; multiple tracks are numbered automatically (e.g., "Drums 1", "Drums 2")

## How to use

1. Right-click any **Audio Track** or **MIDI Track** and choose **Create tracks…**.
2. Select the track **Type** (Audio or MIDI).
3. Set the **Count** (1–64) and enter a **Name**.
4. Click **Create**. New tracks appear at the end of the track list.
