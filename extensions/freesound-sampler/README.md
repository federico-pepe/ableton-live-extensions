# Freesound Sampler

![Freesound Sampler](../../images/Ableton%20Extension%20-%20FreeSound%20Sampler.png)
![Freesound Sampler 2](../../images/Ableton%20Extension%20-%20FreeSound%20Sampler%202.png)

[⬇️ Download](../../download/freesound-sampler.ablx)

Search Freesound.org and download sounds directly into your Ableton Live tracks.

## Features

- **Search and filter** — Query sounds by text with filters for duration, channels, rating, license, and sort order
- **In-dialog preview** — Listen to any result before downloading with the ▶ play button
- **Session and Arrangement View** — Place clips in the first empty session slot, or at the playhead in Arrangement View
- **Persistent API key** — Save your Freesound API key once and reuse it every session
- **Cached downloads** — Already downloaded a sound? The local file is reused automatically

## How to use

1. Get a free API key at [freesound.org/apiv2](https://freesound.org/apiv2).
2. Right-click any **Audio Track** (or an audio lane in Arrangement View) and choose **Find samples**.
3. Enter a search query (e.g., "drums", "pad", "vintage") and paste your API key.
4. Click **Search**, then press ▶ on any result to preview it.
5. Click a sound card to download and import the clip into your track.

> Downloads are 128kbps MP3 preview files — sufficient for sampling and sound design.
