# Duplicate Track

![Duplicate Track](../../images/Ableton%20Extension%20-%20Duplicate%20Tracks.png)

[⬇️ Download](../../download/Duplicate-Track-0.0.7.ablx)

Duplicates an audio or MIDI track without copying its clips.

## Features

- **No clips** — Copies the track configuration (devices, routing, settings) but clears all clips from session and arrangement views
- **Works on both track types** — Audio and MIDI tracks
- **Preserves setup** — Device chain, input/output routing, and track parameters are all copied

## How to use

1. Right-click any **Audio Track** or **MIDI Track**.
2. Select **Duplicate (No clips)**.
3. A new track appears with the same configuration but no clips.
